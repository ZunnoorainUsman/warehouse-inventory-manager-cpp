# Warehouse Inventory Manager (C++)

A simple console-based Warehouse Inventory Management System developed in C++. The project demonstrates file handling, arrays, functions, function overloading, and inventory record management.

## Features

* Add new product shipments
* View stock reports
* Run inventory safety audits
* Standard and custom stock deductions
* Delete products by ID
* Persistent data storage using text files

## Technologies Used

* C++
* File Handling (`ifstream`, `ofstream`)
* Arrays
* Functions
* Function Overloading

## How It Works

The program stores inventory records in a text file where each product contains:

* Product ID
* Quantity

Users can:

1. Add inventory records
2. View all available stock
3. Apply inventory audits
4. Delete inventory records
5. Exit the application

## Concepts Practiced

* File I/O
* Data synchronization between arrays and files
* Menu-driven programs
* Inventory management logic
* Function overloading
* Basic CRUD operations
